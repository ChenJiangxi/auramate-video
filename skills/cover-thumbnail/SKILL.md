# cover-thumbnail — 封面

## 一、最重要的一条

**封面要爆款风（populist + punchy），不要学术风。**

即使视频内容是讲论文的，封面也不能是冷静学者风。片内用学术图表风 OK（符合题材），
封面必须是「巨字 + 戏剧图 + 情绪」。这是踩了 4 版视觉迭代才定下来的：

```
A. 全暗 + 暖金        → 被否
B. 学术 paper-figure 米色 serif → 片内可以，封面不行
C. 极简米色 + 大数字   → 还是太冷静
D. 毛笔字 + 黄 highlight + 红印章 → ✅ 定调
```

---

## 二、构图公式

```
┌─────────────────────┐
│  （戏剧感背景图，上部压暗） │
│                     │
│    巨字第一行          │  ← 字号 ~154，白色
│    巨字第二行（高亮色）   │  ← 强调词换色（金 #F0BE56）
│    ──────           │  ← 短分隔线，同高亮色
│    一行副标           │  ← 字号 ~58，米白
│                     │
│  （底部暗带）           │
│    品牌 · 一句定位      │  ← 字号 ~46，高亮色
└─────────────────────┘
```

尺寸：竖版 **1080×1440**（抖音/小红书），横版 1920×1080（B 站）。

关键技术点（`lib/make-cover.py` 已实现）：

- **顶部渐变压暗**：从上往下 alpha 由 ~220 递减到 ~46，保证巨字在任何背景上都读得清。
- **底部暗带**：最后 280px 再压一层，托住品牌 tag。
- **每层文字都带黑描边**（`stroke_width` 5–8），小屏缩略图下不糊。
- 强调词换色，不要靠加粗——缩略图里粗细看不出来，颜色能。

```bash
/usr/bin/python3 lib/make-cover.py \
  --bg assets/bg.png --out cover.png \
  --line1 "老外，都在算" --line2 "中国八字" \
  --sub "而 AI 算它，已逼近人类冠军" \
  --tag "auramate 灵伴 · AI 玄学出海"
```

## 三、文案规矩

- 第一行 + 第二行合起来 ≤ 12 字。多一个字，字号就得降，冲击力直接掉。
- 副标一行讲清「凭什么点进来」，≤ 20 字。
- **数字比形容词好**：「40 分」「第十七次」「三天没回」。
- 别把视频第一句原封不动搬上封面——封面是**钩子的钩子**。

---

## 四、背景图

- 优先用**成片里的真实画面**抽帧（一致性最好，也证明内容真实）。
- 需要生成图时用图像模型，注意：生成图**只能当背景/氛围**，不能当「证据画面」。
- 抽帧命令：`ffmpeg -ss <秒> -i final.mp4 -frames:v 1 -q:v 2 assets/bg.png`

---

## 五、失败症状 → 修法

| 症状 | 修法 |
|---|---|
| 缩略图上字看不清 | 描边不够 / 没做渐变压暗 / 字太多字号被迫变小 |
| 看着像 PPT | 缺高亮色对比、缺戏剧感背景 |
| 太「学术」 | 换毛笔字/粗黑体 + 高饱和高亮色 + 情绪化文案 |
| 品牌 tag 被背景吃掉 | 底部暗带没加 |
| 竖版封面在平台被裁 | 上下各留 ≥ 100px 安全区 |
