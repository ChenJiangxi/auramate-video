# quality-gate — 交付前的质量闸门

**机器项全过 ≠ 能发。** 这份 skill 的核心就是把两件事分清楚：

```
机器能判的  → audit-video.sh 一条命令跑完，硬失败退出码 1
只有人能判的 → 一张清单，必须真的过一遍，不能当成「已通过」
```

历史上被打回的版本里，**绝大多数栽在「只有人能判的」那一列**——
画幅、时长、音轨这些机器项从来都是对的。

---

## 一、一条命令

```bash
lib/audit-video.sh --project <工程目录> --video <成片.mp4> --target 40-60
```

八项机械检查，逐项出结论：

| # | 查什么 | 底层 |
|---|---|---|
| ① 脚本 | 单拍时长 / 句长 / `ta` / 钩子具体性 / 末句收品牌 | `check-script.py` |
| ② 合规 | 封建迷信红线，**有 BLOCK 直接失败** | `check-compliance.py` |
| ③ 配音 | 每句非空 / 时长合理 / 不是静音 / 语速 | `verify-audio.sh` |
| ④ 分镜 | `shots.tsv` 覆盖每一拍；素材存在且**够长** | 内置 |
| ⑤ 画面构成 | 卡片 / 真实切片 / 产品录屏 各占多少时长 | 内置 |
| ⑥ 字幕 | 条数 == 拆句数，没有漏行 | 内置 |
| ⑦ 成片 | 画幅 / 帧率 / 音轨 / faststart / 时长区间 | `verify-output.sh` |
| ⑧ 交付 | 文件名唯一带版本 / 交付包四件套 | 内置 |

`--strict` 让提示项也算失败。

### ⑤ 画面构成靠目录约定

审计按**素材路径**判断类型，所以目录别乱摆：

```
footage/ext/   → 真实切片
footage/rec/   → 产品录屏
html/beats/    → 卡片（或 shots.tsv 里编码器写 card）
```

超过阈值会提示：卡片 > 60%（「整片都是卡」被明确否过）、产品录屏 < 50%（产品片要求）。

## 二、只有人能判的（机器一条都查不了）

```
[ ] 配音够不够有情绪 —— agent 听不到成品音
[ ] 灵体/主视觉用的是「唤醒态」不是「休眠态」
[ ] 每句台词「说什么显什么」，没有说 A 显 B
[ ] 素材主题精准匹配（讲现代财运别用古钱币）
[ ] 数字全是真跑出来的，没有编的
[ ] 音色配题材（严肃用男主播，别用营销号女声）
[ ] 封面是爆款风不是学术风
[ ] 这条能不能火 —— 创意判断，只能人拍板
```

**正确姿势是在这些点上停下来把候选摆出来问**，而不是自己拍板往下走。

## 三、被打回案例库

每条都是真实发生过的。**看症状对号入座**，别等交付了再返工。

### A. 产品展示不够（最高频，一个选题连打回三版）

| 版本 | 当时怎么做的 | 反馈 | 改法 |
|---|---|---|---|
| v1 | 产品只出现 2 拍 | 展示不够 | 扩到 5 拍 |
| v2 | 5 拍但翻来覆去就命盘 + 对话两个素材 | 还是不够 | 扩到 **6 个不同的面**（解读页 / 论文 / 转场…） |
| v3 | 用的是老素材库里现成的片段 | 素材太有限 | **去现录真实功能页**（完整下拉、生成流程） |

**结论**：产品片里产品展示 ≥ 50% 时长，且要**多个不同的面**，素材不够就去现录。
见 `skills/product-demo/` 的「盘点 → 缺口 → 只补缺口」。

### B. 素材真实性

| 症状 | 反馈原话 | 改法 |
|---|---|---|
| 整片都是 HTML 动画卡 | 「不是全部用 html」「放素材也要放真实的」 | 名人/热点扒本人真实画面；卡只能做标题/钩子 |
| 免费 stock 素材带水印 | — | 下载后必须抽帧看 contact 图（`fetch-clip.sh probe`） |
| 讲现代财运用古钱币 | 素材不搭 | 用现代钞票；下落正好演「财来财去」 |

### C. 画面精致度

| 症状 | 反馈原话 | 改法 |
|---|---|---|
| 裸录屏全屏放 | 「录全屏感觉好小呀，效果一点都不惊艳」 | 裁切放大 1.5–2×（注意分辨率账，见 `skills/product-demo/`） |
| 录屏没有任何包装 | 「不够精致」 | 套假浏览器壳（`wrap-chrome.sh`） |
| 用大黑 `drawbox` 遮不想要的内容 | 「越做越差」 | 改**紧裁**把它裁到画外，或换个时间窗 |
| 主视觉用了休眠态的灵体 | 「这是灵体吗？」 | 必须用唤醒态（点击后等 5–8s 再录） |

### D. 叙事

| 症状 | 反馈原话 | 改法 |
|---|---|---|
| 钩子抽象「你翻了第十七遍」 | 「故事讲明白了吗？」 | 人物 + 动作 + 数字：「他三天没回。你点开他的朋友圈，第十七次。」 |
| 开场是氛围字卡 / 情绪短片 | 「做的越来越差」 | 产品展示 ≥50%，字卡开场压到 ≤4s |
| 一直做「名人/知识/现象」老框 | 要创新、从用户角度 | 点破用户隐秘行为，见 `skills/topic-and-script/` |
| 做「算命=骗局」揭露向 | 反噬产品 | 换正向选题；非做不可就只攻击话术不攻击命理 |

### E. 声音与文字

| 症状 | 改法 |
|---|---|
| 严肃题材用营销号女声 | 换 `presenter_male`；音色按题材选并**每次采样让人挑** |
| 稿子里写 `ta` | TTS 会念成「T-A」→ 写 他 / 她 |
| 字幕贴底（1660） | 抬到下三分之一 **Y≈1400** |
| 字幕漏行 | 必须 1:1 跟音频每一句 |

### F. 品牌与交付

| 症状 | 改法 |
|---|---|
| 录屏地址栏是旧域名 | PIL 打补丁盖成正确域名（`make-brand-assets.py`） |
| 外部素材画面没有品牌角标 | 顶部全程 overlay |
| 封面做成学术风 | 即使内容讲论文，封面也要爆款风 |
| 多版复用同一个文件名 | 前端会缓存，对方永远看到第一版 → 唯一文件名 + zip |
| 自己编数据 | 对方是论文一作，一定被抓 |

## 四、返工成本排序

按「发现得越晚越贵」排：

```
选题错   → 全片重做          ← 最贵，所以 topic.md 要先过合规和框
脚本错   → 配音+字幕+剪辑重来
素材选错 → 重找 + 重剪那几拍
参数错   → 重跑一次脚本      ← 最便宜
```

所以闸门要**前置**：选题定了跑合规、脚本定稿跑 `check-script`，别攒到交付前一次性查。

```
topic.md 定 → check-compliance
clips.json 定 → check-script + check-compliance
配音完 → verify-audio
出片 → audit-video（全量）
```

## 五、失败症状 → 修法

| 症状 | 修法 |
|---|---|
| `AUDIT FAIL` 在②合规 | 有 BLOCK，按词表改，见 `skills/compliance-redlines/` |
| ④ 报「素材从 Ns 起只剩 Xs」 | 换起始点 / 换素材 / `setpts` 放慢 |
| ⑤ 卡片占比过高 | 换真实素材，见 `skills/real-clip-mashup/` |
| ⑥ 字幕条数对不上 | 用了 `--skip` / `--no-merge` 就正常；否则查漏行 |
| ⑦ 报 moov 在文件尾 | 导出漏了 `-movflags +faststart` |
| ⑧ 文件名太通用 | 换成「选题名-vN.mp4」 |
| 审计全过但还是被打回 | 栽在人工那一列了——回上面案例库对号入座 |
