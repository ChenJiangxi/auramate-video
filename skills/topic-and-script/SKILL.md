# topic-and-script — 选题与脚本

**这一环决定 80%。** 素材、剪辑、字幕都是执行；选题错了，执行得再漂亮也救不回来。
反过来，选题对了，哪怕素材粗糙也能跑起来。

顺序不能颠倒：**选题 → 合规过闸 → 脚本 → 分镜表 → 才去找素材。**
没定稿脚本就去剪片，返工的是全部工作。

---

## 一、选题：先落进一个安全表达框

任何一条片子都必须能回答「**这是一条什么内容**」。四个框（详见 `skills/compliance-redlines/`）：

| 框 | 这条片子在干什么 | 真实做过的 |
|---|---|---|
| **技术框** | 讲模型、评测、准确率 | 「全球最强 AI 考中国命理，全部不及格」 |
| **文化框** | 讲术语源流、民俗知识 | 「为什么你存不住钱——财库」 |
| **产品框** | 讲界面、交互、输出 | 功能演示型 |
| **心理框** | 讲一类人的真实状态 | 「承认吧，你也偷偷合过盘」 |

框可以叠加（心理框切入 → 产品框落地是最常用的组合），
但**不能滑向「提供占卜服务」**。选题定了就先跑一次合规：

```bash
/usr/bin/python3 lib/check-compliance.py --project .
```

## 二、角度库：12 条真实交付过的选题，拆给你看

### 心理框 —— 点破用户隐秘行为（最好使，可批量）

人人做过、没人明说的那种行为。被说中 → 转发。

| 选题 | 点破的行为 | 落到什么功能 |
|---|---|---|
| **承认吧，你也偷偷合过盘** | 刚动心就偷偷查你俩合不合 | 缘分匹配 / 合盘 |
| **深夜点开算命 App 的那一刻** | 难受时翻遍通讯录不知发给谁 | 灵体对话 |

**可批量的同类**：裸辞前偷偷算一卦 / 本命年心里发虚 / 总遇上同一类烂桃花 /
面试前查今天宜不宜 / 分手后翻回去看当初的合盘 / 换城市前想找个"说法"。

**写法**：第一人称，不是旁观科普。
> 「承认吧——刚对一个人动心，你还没想好怎么开口，就先偷偷查了你俩合不合。
> 别不好意思，这几乎是本能。」

### 技术框 —— 对比、评测、翻车

| 选题 | 冲突点 |
|---|---|
| **全球最强 AI 考中国命理，全部不及格** | 瞎猜 25 分，最强 40.3 分——反差 |
| **DeepSeek 新版 vs 老版排同一个八字** | 一个全对、一个差一整天，同厂翻车 |

**写法**：给出可核对的数字，讲清测法。**数字必须是真跑的**（`skills/video-master/` H2）。

### 文化框 —— 一个术语 + 一个日常困惑

这是最容易批量、也最安全的一类。公式：

```
日常困惑（观众有共鸣）→ 命理术语解释（考据准确）→ 落到对应功能（严丝合缝）
```

| 选题 | 术语 | 困惑 | 功能 |
|---|---|---|---|
| **为什么你存不住钱** | 财星 / 财库 | 月入过万还是攒不下 | 财运报告 |
| **你适合闯还是守** | 日主身强身弱 | 有人越拼越旺，有人一硬刚就出事 | 专业报告 |
| **肝郁的人，命带伤官** | 伤官 / 五行↔五脏 | 有才、爱较真、爱生闷气 | 命理体检 |

**三条硬要求**：
1. 术语要**精准**——说「伤官是十神之一」，别说「八字里有个字」。
2. 画面要**对上**——讲五脏就显对应脏器，讲财就显现代钞票不是古钱币。
3. 框为**国学 / 自我认知**，**不碰医疗诊断**、不给理财建议。

### 社会框 —— 名人 / 现象

| 选题 | 钩子 |
|---|---|
| **越有钱越信命** | 「你以为信命理的是穷人？李嘉诚、里根都在算」 |

**写法**：名人素材必须是**本人真实画面**（`skills/real-clip-mashup/`），来源可核。

### ⚠ 做过但后来被否的方向

**「算命欠债 9 万」（玄学消费陷阱）**——做过一条，框架是「不是命理假，是话术在割你」。
后来定了规矩：**别做「算命 = 骗局 / 割韭菜」的揭露负面向**，把算命说臭了会反噬命理产品本身。

如果非做反诈不可，唯一安全的框架是：**攻击话术，不攻击命理本身**，落点必须是
「你自己就能算，不用被割」。但优先级上——**换个正向选题更划算**。

## 三、`topic.md` 三件事，缺一不可

```markdown
## 钩子（第一句口播，≤ 25 字）
他三天没回。你点开他的朋友圈，第十七次。

## 为什么这条能火
点破「刚动心就偷偷查对方」这个人人做过、没人明说的隐秘行为。
被说中的人会转发——不是旁观科普，是戳心。

## 落到什么功能
缘分匹配 /play/fate-match —— 合盘分数 + 哪里来电哪里要磨，
跟「他到底喜不喜欢我」严丝合缝。

## 安全框
心理框切入 → 产品框落地。不预言、不承诺、不断关系吉凶。

## 调性 / 音色
情感年轻 → female-tianmei @1.24
```

**选题 → 功能必须严丝合缝。** 讲财运就落财运报告，不是随手挑一个功能——这条被专门挑过。

## 四、钩子：6 个已验证句式

第一句就是主旨。不要娓娓道来。**钩子必须具体**——人物、动作、数字。

| 句式 | 模板 | 实例 |
|---|---|---|
| **承认式** | 承认吧，你也____ | 承认吧，你也偷偷合过盘 |
| **反直觉** | 你以为____？恰恰相反—— | 你以为信命理的是穷人？恰恰相反，越有钱越信 |
| **行为+计数** | 他____。你____，第 N 次。 | 他三天没回。你点开他的朋友圈，第十七次。 |
| **对比翻车** | 我让 A 和 B 做同一件事，看谁行 | 我让新版和老版算同一个八字，看谁准 |
| **数字冲击** | 瞎猜都有 X 分，最强的只有 Y | 随机瞎猜 25 分，最强的也只考了 40.3，全部不及格 |
| **时刻锚定** | ____最诚实的一刻，是____ | 这代年轻人最诚实的一刻，是深夜点开那个算命 App |

### 具体性自检（过不了就重写）

```
零 context 的观众，能不能在 3 拍内看懂发生了什么？
钩子里有没有：① 具体的人 ② 具体的动作 ③ 具体的数字或时间
```

- ❌ 「凌晨两点。你翻了第十七遍。」——翻**什么**？手机？书？观众要猜。
- ✅ 「他三天没回。/ 你点开他的朋友圈，第十七次。/ 他到底喜不喜欢你？」

**钩子不要合并成一行。** 三拍砸下去才有力，合成一句就废了
（字幕侧对应 `gen-subs.py --no-merge`，见 `skills/subtitles/`）。

## 五、脚本：`clips.json` 分句规则

```json
[
 {"name":"c01","text":"他三天没回。你点开他的朋友圈，第十七次。"},
 {"name":"c02","text":"你没想好怎么开口，先偷偷查了你俩合不合。"},
 {"name":"c09","text":"这才是认真做视频该有的样子。"}
]
```

| 规则 | 值 | 为什么 |
|---|---|---|
| 一句 = 一个镜头 = 一段配音 | — | 别把两个画面塞进一句 |
| **单拍时长** | 理想 ≤ 8s，**硬上限 ~15s** | 这才是真约束：一拍 12s 你就要准备 12s 连续画面 |
| 单句字数 | 理想 ≤ 30，**45 字以上要自己确认** | 见下方「不要迷信 30 字」 |
| 句数 | **8–12 句** | 真实交付的片子都在这个区间 |
| 末句 | 用来**收品牌**，不卡字数 | 实测末句往往是最长的一句 |
| 人称 | 写 **他 / 她**，不写 `ta` | TTS 会把 `ta` 念成字母 T-A |
| 停顿 | 用自然标点，别加显式停顿标记 | 长「。」改「，」少一拍 |

### 不要迷信「单句 ≤30 字」

拿真实发过的稿子量过：**9 句里有 4 句超过 30 字**（43 / 61 / 37 / 60），
另一条横版稿甚至有 88 字的句子 —— 都正常交付了。

真正卡人的不是字数，是**这一拍要占多长画面**：

```
实测最长一拍：竖版 48s 片 = 10.04s ；横版 89s 片 = 19.09s
```

一拍 10s 意味着你得有 10s 连续可用的素材。素材撑不住才是问题，字数不是。
所以规则是：**先看这一拍几秒，再看几个字**。长句只要句内标点够（字幕按标点切），
TTS 和字幕都没问题。

## 六、时长换算：用实测值，不要拍脑袋

**这是实测出来的，不是估的**（拿真实成片的 `clips.json` 和配音文件量的）：

| 音色 / 速度 | 含标点 字/秒 | 纯汉字数字 字/秒 | 样本 |
|---|---|---|---|
| 克隆音 @ 1.10 | **4.98** | 4.04 | 89.2s / 7 句（整片） |
| `presenter_male` @ ~1.30 | **6.35** | 5.10 | 52.3s / 9 句（整片） |
| `presenter_male` @ 1.28 | 6.13 | 5.21 | 单句 20 字 |
| `female-shaonv` @ 1.28 | **6.40** | 5.44 | 单句 20 字 |
| `female-tianmei` @ 1.28 | **5.37** | 4.56 | 单句 20 字 |

`female-tianmei` 明显比另外两个慢（同一句慢 15%）——情感题用它，字数要相应少写。

**注意**：写稿时你数的是 `len(text)`，那是**含标点**的数。用含标点那一列。

**这个估算只能到 ±10%。** 留出法验过：拿前 5 句拟合语速去预测后 4 句，误差 8.8%。
所以**配完音必须 ffprobe 实测一次**，别拿估算值去排时间轴。

```
presenter_male @1.30，目标 60s  →  约 380 字（含标点）
presenter_male @1.30，目标 75s  →  约 475 字
presenter_male @1.30，目标 90s  →  约 570 字
克隆音      @1.10，目标 60s  →  约 300 字
```

> 早期用「5 字/秒」估，实测 6.35 —— 按 5 写会**超出约 27%**，
> 一条按 75s 写的稿子实际只有 59s。**配完音一定要用 ffprobe 实测一次总时长再往下走。**

真实交付的成片时长分布：**42.6 / 45.7 / 48.1 / 52.3 / 53.7 / 56.0 秒** —— 都在 40–60s。
抖音竖版这个区间最稳，别硬凑到 90s。

## 七、结构：时间预算

```
钩子      0–4s      第一句，具体，三拍砸下去
展开      4–?       一句一个信息点，别原地打转
产品      ≥ 50%     真实界面 + 真实操作 + 真实输出（产品片）
收尾      最后一拍   收品牌。实测这一拍往往是全片最长的一句（要把产品讲完），不卡字数
```

框定话术（把结果定性为「参考 / 换个角度认识自己 / 传统文化说法」）**全片至少出现一次**，
自然带过，别念免责声明。

## 八·五、人味儿：这段话是人在说，还是 AI 在念

写完稿最容易忽略的一关。技术上全对——字数够、单句不长、没有违禁词——
听起来还是像播报。因为**没人站在这段话背后**。

```bash
/usr/bin/python3 lib/check-humanness.py --project .
```

### 人味儿是三件事（顺序不能反）

1. **位置。** 背后有一个具体的人，站在具体的位置说话。
   同一句话换个人说还成立，就说明没有位置。
2. **代价。** 这个判断是他真经历过换来的。读者隔着屏幕闻得出来
   哪句话背后有生活、哪句话背后只有词库。
3. **手迹。** 语气词、重复、不工整的呼吸，是这个人说话的样子。
   书面语标准下它们「冗余」，但删掉之后人就没了。

### 两个最省事的信号

真实案例：一版稿子技术上全绿，读着还是讲解员腔。查下来就两件事——
**八句里没有一个「我」，没有一个语气词**。

| 症状 | 意味着 | 改法 |
|---|---|---|
| 全篇没有「我」 | 没人站在这段话背后 | 产品片尤其：讲「我为什么做这个」比讲「它有什么功能」有人味儿 |
| 全篇没有语气词（吧/呢/啊） | 在念稿，不是在说话 | 留一两个。它们携带叹气、自嘲、犹豫 |

改之前 vs 改之后（同一条 demo）：

```
✗ 你把生日输进去，三秒，出来八个字。
  然后你盯着这八个字，一个也看不懂。       ← 全程「你」，像在指导观众

✓ 输个生日进去，三秒，出来八个字。
  我第一次看见的时候，一个也不认识。       ← 有「我」，是一个人的经历
  ……日主偏弱、喜什么忌什么，这些话得先翻成人话吧。   ← 「吧」带出一声叹气
```

### AI 句式痕迹（机器能查的部分）

破折号 `——`（最可靠的信号，全删）· 「不是X而是Y」· 排比三连 ·
意义拔高（标志着/体现了/折射出）· 宣传腔（赋能/匠心/极致体验）·
万能展望结尾（未来可期/拭目以待）· 签到式过渡（让我们/接下来看看）·
自问自答（「结果呢？惨烈。」）· 假坦诚开场（「说实话，……」）

> 清单提炼自 Wikipedia「Signs of AI writing」（经 blader/humanizer, MIT），
> 底层原理来自 renwei-writing（人味儿写作）。

### 改稿时的三条戒律

- **只做减法，少动。** 每处改动要能说出原文哪里真的打绊了。动三处是常态，动十处是事故。
- **毛边先当手迹，不当瑕疵。** 删之前问：删掉以后，说话的人还在吗？
- **不写金句。** 你写出工整对仗或漂亮比喻的那一刻，是你在表演，不是他在说话。
  拿不准就往白描走——素一点不会把人改没。

## 九、机器自检

```bash
/usr/bin/python3 lib/check-script.py --project . --rate 6.35 --target 40-60
```

三道闸门一起跑：

```bash
/usr/bin/python3 lib/check-script.py     --project . --target 40-60   # 技术
/usr/bin/python3 lib/check-humanness.py  --project .                  # 人味儿
/usr/bin/python3 lib/check-compliance.py --project .                  # 合规
```

`check-script.py` 查：句数 / 总字数 / 预估时长（用实测语速）/ **单拍时长**（>15s 硬错误、>8s 提示）/
单句字数（>45 字提示）/ 句子过短 / `ta` 未写成汉字 / 末句有没有收品牌 /
钩子具体性（人物、动作、数字）/ 句式重复 / 有没有框定话术。

有**硬错误**退出码 1。软提示只是提醒，人工判断。

配完音之后再用真实时长复核一次：

```bash
lib/verify-audio.sh audio/ clips.json     # 会打印配音总时长
```

## 十、常见废稿特征（出现就重写，别抢救）

1. **钩子抽象**——观众要猜「你在说什么」。
2. **原地打转**——三句话说的是同一件事，没有推进。
3. **选题和功能对不上**——讲财运却演示了个别的功能。
4. **全程科普口吻**——心理框的题用了旁观第三人称，戳不到人。
5. **末句没收住**——最后一拍没落到品牌/产品，观众看完不知道去哪。
6. **数字是编的**——一定被抓，且是信任问题不是质量问题。
7. **老框里打转**——「名人 / 知识 / 现象」做过太多次了，要从用户真实心理找新角度。

## 十一、失败症状 → 修法

| 症状 | 根因 | 修法 |
|---|---|---|
| 成片比预期短 20%+ | 用 5 字/秒 估的 | 改用实测语速表，配完音 ffprobe 复核 |
| 某一拍没画面可配 | 脚本写完才想素材 | 写稿时同步列镜头表，一句一个来源 |
| 配音喘不上气 | 长句里没有足够标点 | 加逗号断气口，不一定要拆句 |
| 某一拍找不到够长的素材 | 这一拍预估 >10s | 拆句，或 `setpts` 放慢现有素材 |
| TTS 念出「T-A」 | 稿里写了 `ta` | 改成 他 / 她 |
