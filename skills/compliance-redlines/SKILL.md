# compliance-redlines — 内容合规红线

**这一节的优先级高于所有手艺规则。** 片子做得再好，违规就是限流 / 下架 / 封号，
前面所有工作归零。做命理 / 玄学 / 算命题材，先过这一关再谈别的。

---

## 一、一句话原则

> **宣扬封建迷信必违规；讲 AI 算命、讲产品功能不违规。**

区别不在题材，在**这条片子在干什么**：

| 这条片子在干什么 | 判定 |
|---|---|
| 讲 AI 能不能排八字、模型准确率、怎么训练的 | ✅ 科技内容 |
| 展示产品界面、交互、输出形态 | ✅ 软件演示 |
| 讲干支 / 五行 / 节气的文化源流 | ✅ 文化科普 |
| 讲一种人群的心理状态、引发共鸣 | ✅ 情感 / 自我认知 |
| **提供占卜服务、承诺改运避灾、预言具体祸福** | ❌ 宣扬封建迷信 |
| **用玄学解释不幸并给出玄学解法** | ❌ 宣扬封建迷信 |
| **恐吓 + 引流**（"不改会出事，加我算"） | ❌ 双重违规，最容易封号 |

同一个产品功能，说法不同，一边合规一边违规：

```
✅ 「这套 AI 会怎么描述你的性格倾向」        —— 展示输出，框为参考
❌ 「测一测你今年会不会破财，教你怎么化解」   —— 预言祸福 + 承诺化解
```

## 二、明确违规的七类（BLOCK，出现即改）

1. **承诺改变命运**：转运、改运、改命、开运、旺财、旺夫、续命。
2. **消灾解厄**：化解、消灾、破解、挡煞、保平安、破财免灾。
3. **迷信仪式**：开光、符咒、做法事、招财阵、请神、供奉。
4. **预言具体祸福**：血光之灾、犯太岁必有灾、几月有难、断生死。
5. **恐吓营销**：不看必悔、不改会出事、躲不过这一劫。
6. **神化与虚假宣传**：大师亲算、神准、包准、百分百准、必定应验。
7. **算命引流**：加微信算、私信测算、扫码进群、免费给你算一卦。

> 第 7 条尤其致命 —— **玄学 + 私域引流**在各平台都是重点打击组合，
> 比单纯内容违规处罚重得多。这套 skill 只做内容，**永远不要在片中引导私加**。

---

## 三、高风险（WARN，需要人工确认或改写）

- **绝对化断言**：注定、必然、一定会、命中注定、躲不过。
  → 改成「传统说法里…」「这类命局常被描述为…」「倾向于」。
- **凶吉断事**：凶、劫难、厄运、冲太岁、断事。
  → 只做**描述性**表达，不做**结论性**判决。
- **医疗越界**：治好、治愈、病根、确诊、吃什么药、处方。
  → **命理不碰医疗**。可以讲「五行↔五脏」的**文化对应关系**，
  绝不给诊断和治疗建议，也不暗示可以替代就医。
- **财务越界**：财运暴涨、一夜暴富、该不该买、投资建议。
  → 不给任何投资 / 财务决策指引。
- **婚恋越界**：不合就分、克夫、命里犯桃花所以要防。
  → 不对真实关系下判决，尤其不针对具体可识别的人。
- **未成年人向**：不做面向未成年人的命理内容。

## 四、安全表达框架（把片子放进这四个框之一）

做选题时先想清楚**这条片子属于哪一框**，然后全片措辞都服从这个框：

| 框 | 定位 | 措辞基调 | 例子 |
|---|---|---|---|
| **技术框** | 这是 AI / 模型内容 | 评测、准确率、模型对比、怎么训练 | 「让最强的模型考命理真题，看谁排盘不出错」 |
| **文化框** | 这是传统文化科普 | 源流、术语、历史、民俗 | 「伤官是十神之一，古人用它描述一类性情」 |
| **产品框** | 这是软件演示 | 界面、交互、输出 | 「点进去它会生成这样一份报告」 |
| **心理框** | 这是自我认知 / 共鸣 | 觉察、参考、情绪 | 「你也偷偷查过合不合吧」——点破行为，不做预言 |

四个框可以叠加，**但任何一框都不允许滑向「提供占卜服务」**。

**框定话术**：全片至少出现一次把结果定性为「参考 / 自我觉察 / 传统文化说法 / 娱乐」的表述。
自然一点，别念免责声明。例如收尾一句：

> 「就当是换个角度认识自己 —— 信不信，你自己判断。」

## 五、逐词替换表

| 高危表达 | 改成 |
|---|---|
| 算你的命 / 给你算一卦 | 看看传统命理怎么描述这类人 |
| 预测 / 预言 | 描述 / 参考 / 这套说法里 |
| 注定 / 必然 / 一定会 | 倾向于 / 常被描述为 / 更容易 |
| 转运 / 改运 / 开运 | （删掉，不替换） |
| 化解 / 消灾 / 破解 | （删掉，不替换） |
| 大师 / 神准 / 包准 | （删掉，不替换） |
| 犯太岁 / 血光之灾 | （删掉，不替换） |
| 治好 / 调理好你的病 | 传统文化里把这类状态叫作…（不给医疗建议） |
| 加我微信免费测 | （删掉，永远不引流） |

**「删掉，不替换」的意思就是这个卖点不要了。** 不要试图换个说法保留同样的承诺——
审核看的是实质，不是字面。

## 六、题材层面的两条补充

1. **别做「算命 = 骗局 / 割韭菜」的揭露负面向。**
   把「算命」说臭了会反噬命理产品本身，而且这类内容同样容易被判为争议话题。
   要「有趣 / 共鸣 / 名人 / 技术」正向。

2. **数字必须真。** 测评分数、准确率只用真跑出来的值。
   编数字既是内容失信，也可能构成虚假宣传。

## 七、机器自检（每条片子必跑）

```bash
/usr/bin/python3 lib/check-compliance.py --project <你的工程>
```

它扫 `clips.json`（口播稿）、`topic.md`（选题）、`caption.txt`（平台文案），分三档：

- **BLOCK** —— 出现即必须改，退出码 1。
- **WARN** —— 高风险，人工确认这句到底在说什么。
- **INFO** —— 建议项（比如全片没有任何框定话术）。

口播稿定稿前跑一次，交付前再跑一次（文案也要过）。

> 机器只能查词，**查不了语义**。「不用改运，看看就好」这种否定式表达会被误报，
> 人工判一下即可；反过来，不含任何高危词但整体在承诺祸福的片子，机器也拦不住。
> **最终判断在人。**

## 八、交付前三问

```
1. 这条片子有没有承诺一个玄学结果（转运 / 避灾 / 预言具体事件）？
2. 有没有用玄学替代医疗 / 投资 / 法律 / 教育决策？
3. 把产品拿掉之后，这条片子是在科普、讲技术、讲情绪，
   还是在提供占卜服务？
```

三问全部过了，再走 `skills/delivery/` 的交付流程。

## 九、失败症状 → 修法

| 症状 | 根因 | 修法 |
|---|---|---|
| 发布后播放量异常低（限流） | 触碰封建迷信 / 引流红线 | 按上面词表逐句改写，重新发 |
| 审核不通过 | 承诺祸福或迷信仪式 | 删掉承诺，改成描述性表达 |
| 账号被警告 | 玄学 + 私域引流组合 | 永远不在片中引导私加 |
| 内容被判医疗违规 | 命理话术滑进诊断建议 | 只讲文化对应关系，不给诊断和治疗建议 |
| 片子改完变得没劲 | 卖点本来就建立在违规承诺上 | 换选题角度——技术 / 文化 / 心理框里有大量安全且有力的选题 |
