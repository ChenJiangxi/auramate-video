# 拆一条产品展示片：知时「同时不同命吗」

**为什么拆这条**：它和 `douyin-case-formsight.md` 那条是**两种相反的形态**，
放一起看才知道"产品展示"有几种做法。这条是**纯产品巡览**，没有观点输出，
靠"把功能一个个演给你看"拿到 3.8 万赞 —— 这正是我们做 auramate 产品片要学的那种。

## 一、口播（抄下来的，注意语气）

```
… 专门用来研究国学
截止到目前 / 现在它的能力跟刚开始比
除了基础的排盘功能 / 比如说这些是排盘功能
啊这个专业内容为了 …
他还可以给你判断一些专业内容
然后身强身弱喜用忌 / 还有你的格局的一个判定
给你一个比较 / 然后我就不在这一一展示了
例如说啊我这个人带什么东西
然后输入完信息之后 …
听懂才是最好的结果
```

**全是口语**：「比如说」「例如说啊」「然后下边呢」「我就不在这一一展示了」。
没有一句播音腔。这条对我们最直接 —— 我们的 `check-humanness.py` 卡的就是这个。

## 二、取景：**切**，不是推拉（这条最值钱）

隔 0.5 秒抽帧量的：

```
43.0s → 43.5s   几乎不动
44.0s           突然切到大特写（四柱那一行占满画幅）
44.5s           又切回宽景
```

**平均 2–2.5 秒换一个机位，近景 ↔ 宽景来回切，密度比配音句子还高。**
不是连续推拉 —— 连续推拉（`punch-in` / `kenburns`）都从全屏起手，
"要看清某个字段"的拍会有大半段还是小画面。

做法和踩过的三版见 `skills/product-demo/` 二·9。

## 三、能直接抄的

1. **横版录屏放竖屏中间 + 上下黑边 + 字幕压在黑边里**。不拉满、不裁两头。
2. **一拍超过 4 秒就拆机位**，近远交替。
3. **口播用大白话**，带语气词。讲解式，不是宣传腔。
4. **最后真的用一次**（他输入「我这个人带什么东西」看输出），不是只看界面。
5. **落在一句产品主张上**（「听懂才是最好的结果」）。

## 四、不能照抄的

- **19 秒影视剧切片**：版权和合规都过不去，而且前 19 秒不出产品对我们太奢侈。
  我们的替代是 HTML 钩子大字卡（硬规矩 H1 允许卡做钩子）。
- **直接用 #八字命理 #国学智慧 这类标签**：他敢用是因为内容是纯功能演示、
  不做任何结果承诺。我们发之前仍要过 `lib/check-compliance.py`，
  而且我们的口播里带产品主张，风险面比他大。
- **114 秒**：他能撑这么长是因为功能真的多且一个个演。功能不够就别注水，
  40–60 秒讲清楚一件事更稳。
