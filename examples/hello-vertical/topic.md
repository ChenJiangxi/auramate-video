# topic.md — 样例（心理框切入 → 产品框落地）

> 这是 `skills/topic-and-script/` 里 `topic.md` 模板的一个填好的样例。
> 换成真选题时照这个结构写，五节都要有。

## 钩子（第一句口播）

他三天没回。你点开他的朋友圈，第十七次。

**为什么这样写**：人物（他）、动作（点开朋友圈）、数字（第十七次）三样齐全，
零 context 的观众 3 拍内就懂了发生什么。
对照反例：「凌晨两点。你翻了第十七遍。」——翻什么？观众要猜，废。

## 为什么这条能火

点破「刚动心就偷偷查对方」这个人人做过、没人明说的隐秘行为。
被说中的人会转发——不是旁观科普，是戳心。

同类可批量：裸辞前偷偷算一卦 / 本命年心里发虚 / 总遇上同一类烂桃花 /
面试前查今天宜不宜 / 分手后翻回去看当初的合盘。

## 落到什么功能

缘分匹配（合盘）——合盘分数 + 哪里来电哪里要磨，
跟「他到底喜不喜欢我」这个问题严丝合缝。

**选题 → 功能必须对得上**：讲财运就落财运报告，不能随手挑一个别的功能。

## 安全框

心理框切入 → 产品框落地。

- 讲的是**一类人的真实状态**和**产品输出长什么样**，不是占卜服务。
- 不预言具体事件、不承诺结果、不对真实关系下吉凶判决。
- 全片至少一次框定话术：「就当是换个角度认识自己，信不信你自己判断。」

跑一次确认：

```bash
/usr/bin/python3 ../../lib/check-compliance.py --project .
```
